Option 1: Quick WebView APK (No File System Access)

Step 1: Use an Online APK Builder

Go to one of these websites:

  • WebsiteToApp.com
  • GoNative.io
  • WebIntoApp.com

Step 2: Configure Your App

Use these settings:

  • App Name: Trimble Sync
  • URL: http://pardysurveys.direct.quickconnect.to:3000/
  • Package Name: com.pardysurveys.trimblesync
  • Enable:
    • ✅ File Upload
    • ✅ File Download
    • ✅ JavaScript
    • ✅ Location Access
    • ✅ Camera Access

Step 3: Download and Install

  1. Download the generated APK
  2. Transfer to your TSC5 via USB or download directly
  3. Enable "Install from Unknown Sources" on TSC5
  4. Install the APK
⚠️ Limitation: This method creates a simple web wrapper. It won't have access to the TSC5's file system (/sdcard/Trimble Data/Projects/), so file syncing will be manual through the browser's file picker.

Option 2: Full-Featured APK (With File System Access)

For Full TSC5 Integration

To build an app that can:

  • Access /sdcard/Trimble Data/Projects/ directly
  • Launch Trimble Access with specific jobs
  • Auto-sync files between TSC5 and NAS

You'll need Android Studio. The code is ready in:
\\ps-nas\pardy surveys\Data Sync\trimble-sync-android\

Manual Sync Workflow (Current Solution)

From Office to Field:

  1. Office creates job in web portal
  2. Click "Sync to Controller"
  3. On TSC5: Open portal, go to Controller section
  4. Long-press job folder and "Download" files
  5. Save to /sdcard/Trimble Data/Projects/

From Field to Office:

  1. Complete job in Trimble Access
  2. Export CSV and DXF files
  3. Open portal on TSC5
  4. Navigate to the job folder
  5. Use "Upload" to add exported files
  6. Office sees updated files immediately
